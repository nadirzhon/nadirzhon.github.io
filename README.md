# Сайт студии

Двуязычный сайт (RU/EN) для привлечения клиентов: услуги, кейсы, блог, расчёт стоимости рутины, форма заявки.
Astro 5 + Tailwind 4, полностью статический — раздаётся с любого хостинга, работает без сервера и базы.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # готовый сайт в dist/
npm run preview  # посмотреть собранное
```

---

## Что заменить в первую очередь

Всё, что относится к вам лично, лежит в одном файле — **`src/data/site.ts`**:

| Поле | Что это |
|---|---|
| `brand`, `brandMark` | Название и две буквы в логотипе |
| `domain` | Домен без протокола |
| `email`, `telegramUrl` | Куда приходят заявки. На странице не показываются |
| `city` / `cityEn` | Город в подвале |
| `formAccessKey` | Ключ приёма заявок, см. ниже |

Ещё два места с доменом: `astro.config.mjs` (поле `site` — от него строятся sitemap и canonical) и `public/robots.txt`.

## Заявки с формы

Форма подключена к [Web3Forms](https://web3forms.com) и работает: заявки уходят на почту в фоне,
посетителю ничего дополнительно делать не нужно. Бесплатный тариф — 250 писем в месяц.

Ключ лежит в `src/data/site.ts` (`formAccessKey`). Если понадобится сменить почту получателя —
это делается в личном кабинете Web3Forms, код трогать не нужно.

**Личные контакты на сайте не показываются.** Ни почты, ни ника в Telegram в разметке нет —
единственный вход это форма. Так адреса не попадают в спам-базы, а все обращения приходят
в одном формате и не теряются по разным каналам.

**Заявки в Telegram.** Форма умеет дублировать заявку в Telegram, чтобы она приходила мгновенно.
Токен бота при этом не попадает в код сайта — он живёт в бесплатном Cloudflare Worker.
Пошаговая настройка на десять минут: [`worker/README.md`](worker/README.md).

Устройство: скрытое поле `botcheck` отсеивает спам-ботов; тема письма содержит имя отправителя,
чтобы заявки различались в ящике; адрес из поля «Почта или Telegram» подставляется в Reply-To,
поэтому отвечать можно прямо из письма. Если ключ убрать, форма вернётся к запасному режиму —
откроет почтовый клиент с готовым письмом.

## Где что менять

| Что | Файл |
|---|---|
| Услуги: названия, описания, цены, сроки, стек | `src/data/services.ts` |
| Все тексты интерфейса, этапы работы, пакеты, FAQ | `src/data/i18n.ts` |
| Кейсы | `src/content/cases/*.md` |
| Записи блога | `src/content/posts/*.md` |
| Цвета, шрифты, размеры | `src/styles/global.css`, блок `@theme` |

### Добавить кейс

Скопируйте `src/content/cases/_shablon-ru.md`, переименуйте (например `apteka-ru.md`), заполните и уберите `draft: true`.
Имя файла задаёт адрес: `apteka-ru.md` → `/keysy/apteka/`. Английская версия — тот же файл с суффиксом `-en`.

Правила, из-за которых кейсы работают, записаны внутри шаблона. Коротко: цифры только те, что подтвердит клиент;
название компании — только с письменного разрешения; обязательно раздел «где было больно».

### Добавить запись в блог

То же самое: `src/content/posts/_shablon-ru.md` → скопировать → заполнить → убрать `draft: true`.

## Публикация

Сайт уже опубликован на GitHub Pages: **https://nadirzhon.github.io/**
Каждый `git push` в `main` пересобирает и выкладывает его — вручную ничего запускать не нужно.

### Переезд на свой домен

Три шага, код при этом не меняется:

1. Создайте файл `public/CNAME` с одной строкой — вашим доменом без протокола:
   ```
   example.ru
   ```
2. У регистратора домена пропишите записи DNS:
   ```
   A     @   185.199.108.153
   A     @   185.199.109.153
   A     @   185.199.110.153
   A     @   185.199.111.153
   CNAME www nadirzhon.github.io
   ```
3. `git push` — сборка увидит `public/CNAME`, соберёт сайт под ваш адрес без префикса,
   а GitHub сам выпустит бесплатный сертификат HTTPS (обычно за 10–30 минут).

Обновите также `domain` в `src/data/site.ts` — он попадает в разметку для поисковиков.

Другие варианты, если понадобятся: `npx vercel --prod` или `npx netlify deploy --prod --dir=dist`
(перед этим `npm run build`); свой сервер — положить содержимое `dist/` в корень nginx.

После подключения домена добавьте сайт в
[Яндекс.Вебмастер](https://webmaster.yandex.ru) и [Google Search Console](https://search.google.com/search-console) —
карта сайта уже генерируется по адресу `/sitemap-index.xml`.

## Устройство

```
src/
├── data/          site.ts (контакты) · services.ts (услуги) · i18n.ts (тексты, этапы, пакеты, FAQ)
├── components/    Hero, Services, Calculator, Method, CaseList, Pricing, Faq, Contact, Header, Footer
├── content/       cases/ и posts/ — markdown
├── layouts/       Base.astro — head, мета-теги, разметка для поисковиков
├── pages/         RU в корне, EN в /en/
└── styles/        global.css — вся дизайн-система
```

Русская версия живёт в корне (`/`, `/uslugi/…`, `/keysy/`, `/blog/`), английская — в `/en/`.
Переключатель языка в шапке ведёт на ту же страницу на другом языке через свойство `altPath`.

## Дизайн

Палитра — сталь, латунь, мох, графит: корпус измерительного прибора.
Шрифты: Unbounded (заголовки), Manrope (текст), JetBrains Mono (данные и подписи) — все с кириллицей.

Всё держится на переменных в `@theme` внутри `global.css`. Меняете там — меняется на всём сайте.

Проверено: раскладка от 390 px, навигация с клавиатуры, `prefers-reduced-motion`,
работа без JavaScript (секции видны, форма отправляет письмо).

# Заявки в Telegram

Форма на сайте отправляет заявку в два места сразу: на почту через Web3Forms и в Telegram
через этот ретранслятор. Работают оба канала — отказ одного не мешает другому.

## Что уже развёрнуто

| Что | Где |
|---|---|
| Воркер | `autonoma-leads`, адрес `https://tg.autonoma.uk` |
| Журнал заявок | KV-хранилище `autonoma-leads` (привязка `LEADS`) |
| Вебхук бота | `https://tg.autonoma.uk/tg`, подписан секретом |
| Адрес в коде сайта | `telegramRelay` в `src/data/site.ts` |

Воркер отвечает по двум путям:

- `POST /` — заявка с сайта: уходит в Telegram и попадает в счётчик
- `POST /tg` — сюда Telegram присылает команды боту

## Команды бота

- `/stats` — сколько заявок пришло всего, за 7 и за 30 дней, разбивка по направлениям
  и по бюджетам, время последней заявки
- `/start`, `/help` — короткая справка

Посторонним бот не отвечает: сообщения принимаются только от `CHAT_ID`.

## Зачем нужен ретранслятор

Токен бота нельзя класть в код сайта: сайт публичный, и токен увидит любой желающий.
Тот, кто его получит, сможет писать вам от имени вашего же бота.

Поэтому токен живёт в секретах Cloudflare Workers — бесплатно, 100 000 запросов в сутки.
Сайт стучится к воркеру, воркер знает токен и передаёт сообщение в Telegram.

## Переменные

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен от @BotFather |
| `CHAT_ID` | Secret | числовой id получателя, его сообщает @userinfobot |
| `WEBHOOK_SECRET` | Secret | произвольная строка, ею Telegram подписывает запросы к `/tg` |
| `ALLOWED_ORIGIN` | Text | адреса сайта через запятую, без слэша на конце |
| `LEADS` | KV | хранилище журнала заявок |

Без привязки `LEADS` воркер продолжает работать: заявки приходят, а `/stats` честно
сообщает, что журнал не подключён.

## Как выложить изменения

```sh
cd worker
npx wrangler login          # один раз
npx wrangler deploy         # выкладывает telegram-relay.js
```

Секреты в репозитории не хранятся — при первом развёртывании на новом месте задайте их:

```sh
npx wrangler secret put BOT_TOKEN
npx wrangler secret put CHAT_ID
npx wrangler secret put WEBHOOK_SECRET
```

И привяжите вебхук к боту (`<СЕКРЕТ>` — то же значение, что в `WEBHOOK_SECRET`):

```sh
curl -X POST "https://api.telegram.org/bot<ТОКЕН>/setWebhook" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://tg.autonoma.uk/tg","secret_token":"<СЕКРЕТ>","allowed_updates":["message"]}'
```

## Если сообщения перестали приходить

1. `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo` — покажет последнюю ошибку
2. Логи воркера: Cloudflare → Workers → `autonoma-leads` → Logs
3. Частые причины: не нажали `/start` своему боту; в `ALLOWED_ORIGIN` адрес со слэшем
   на конце; сменился домен сайта, а в переменной остался старый

# Заявки в Telegram

Форма на сайте отправляет заявку в два места сразу: на почту через Web3Forms и в Telegram
через этот ретранслятор. Почта уже работает, здесь — про Telegram.

## Зачем нужен ретранслятор

Токен бота нельзя класть в код сайта: сайт публичный, и токен увидит любой желающий.
Тот, кто его получит, сможет писать вам от имени вашего же бота.

Поэтому токен живёт в Cloudflare Workers — бесплатно, 100 000 запросов в сутки, карта не нужна.
Сайт стучится к воркеру, воркер знает токен и передаёт сообщение в Telegram.

## Что сделать — примерно десять минут

### 1. Создать бота

В Telegram напишите **@BotFather** → `/newbot` → придумайте имя и логин.
В ответ придёт строка вида `8123456789:AAH...` — это **BOT_TOKEN**.

### 2. Узнать свой id

Напишите **@userinfobot** любое сообщение. Он ответит числом вида `123456789` — это **CHAT_ID**.

Важно: после этого напишите своему боту `/start`, иначе Telegram не разрешит ему писать вам первым.

### 3. Развернуть воркер

1. Заведите аккаунт на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатно)
2. **Compute (Workers)** → **Create** → **Start from Hello World** → **Deploy**
3. Откройте **Edit code**, удалите содержимое и вставьте всё из `telegram-relay.js` → **Deploy**
4. Вкладка **Settings → Variables and Secrets** → добавьте три переменные:

   | Имя | Тип | Значение |
   |---|---|---|
   | `BOT_TOKEN` | Secret | токен от BotFather |
   | `CHAT_ID` | Secret | ваш числовой id |
   | `ALLOWED_ORIGIN` | Text | `https://nadirzhon.github.io` |

5. Скопируйте адрес воркера — вида `https://имя.ваш-логин.workers.dev`

### 4. Подключить к сайту

Впишите адрес в `src/data/site.ts`:

```ts
telegramRelay: 'https://имя.ваш-логин.workers.dev',
```

`git push` — и заявки начнут приходить в Telegram вместе с письмом на почту.

## Проверка

Отправьте заявку через форму на сайте. Должны прийти письмо и сообщение в Telegram.
Если сообщения нет — откройте воркер в Cloudflare, вкладка **Logs**, там будет причина.

Частые причины: не нажали `/start` своему боту; перепутаны местами BOT_TOKEN и CHAT_ID;
в `ALLOWED_ORIGIN` указан адрес со слэшем на конце (его быть не должно).
